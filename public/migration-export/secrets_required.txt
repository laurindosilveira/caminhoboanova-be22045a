LISTA DE SECRETS NECESSÁRIOS (CONFIGURAR NO NOVO SUPABASE)

1. STRIPE_SECRET_KEY
   - Necessário para integração de pagamentos e assinaturas.
2. STRIPE_WEBHOOK_SECRET
   - Necessário para validar webhooks do Stripe.
3. VAPID_PUBLIC_KEY
   - Necessário para Push Notifications (Web Push).
4. VAPID_PRIVATE_KEY
   - Necessário para Push Notifications (Web Push).
5. WHATSAPP_API_URL
   - URL da API de integração com WhatsApp.
6. WHATSAPP_API_TOKEN
   - Token de autenticação da API de WhatsApp.
7. WHATSAPP_INSTANCE_ID
   - ID da instância do WhatsApp.
8. APP_URL
   - URL base do seu novo frontend (ex: sua-app-vercel.app).
9. SUPABASE_URL (Geralmente automático)
10. SUPABASE_SERVICE_ROLE_KEY (Geralmente automático)

NOTA: Certifique-se de copiar os valores exatos do projeto antigo ou gerar novos se for trocar de conta (como VAPID keys).
